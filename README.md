# Python Dictionary Practice 🐍

A simple Python program demonstrating how to create, access, and update values in a dictionary.

## 📌 About the Project

This project is a beginner-level Python exercise using a dictionary to store information about a student.

The program demonstrates how to:

- Create a dictionary
- Store key-value pairs
- Access a value from a dictionary
- Update an existing value
- Print dictionary values to the console

## 💻 Code

```python
student = {
    "name": "fred",
    "university": "QMUL",
    "age": "44",
}

print(student["university"])

student["age"] = 48
print(student["age"])
```

## ▶️ Output

When you run the program, the output will be:

```text
QMUL
48
```

## 🧠 What I Learned

This exercise helped me understand how Python dictionaries work.

For example:

```python
student["university"]
```

accesses the value stored under the `"university"` key.

You can also update a value using:

```python
student["age"] = 48
```
